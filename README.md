# Refactorisation d'un Code PHP Procédural

## Contexte du Projet
Ce projet consiste à refactoriser un code PHP écrit de manière procédurale, fourni par un camarade de classe. L'objectif est d'améliorer la lisibilité, la maintenabilité et la structure du code en appliquant les bonnes pratiques de développement PHP.

## Objectifs
1. Analyser et comprendre le code original.
2. Identifier les points d'amélioration : éliminer la redondance, améliorer la lisibilité, rendre le code plus modulaire.
3. Refactoriser le code pour appliquer une structure plus claire et organisée.

## Contenu du Projet
- **`original-code.php`** : Le code initial, tel qu'il a été fourni.
- **Dossier `Sapin/`** : Code refactorisé organisé en différentes classes et fichiers.
